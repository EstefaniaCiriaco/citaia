# Glowback Client Reminders

DESARROLLO WEB PROFESIONAL: CitaIA

Actúa como un diseñador UX/UI senior especializado en productos SaaS y como desarrollador frontend experto en React, TypeScript y diseño responsive.

Quiero que diseñes y desarrolles un sitio web completo, moderno e interactivo para un proyecto llamado CitaIA.

El objetivo es crear una plataforma conceptual que ayude a pequeños negocios de servicios personales a organizar el seguimiento de sus clientes, identificar cuándo podrían necesitar nuevamente un servicio y facilitar su regreso mediante recordatorios personalizados.

IMPORTANTE: No quiero una página genérica, infantil ni con apariencia de plantilla. Busco una identidad visual sofisticada, profesional y tecnológica, comparable con una startup SaaS real.

1. IDENTIDAD DE MARCA

Nombre: CitaIA

Eslogan: Tus clientes regresan. Tu negocio crece.

Concepto: Inteligencia de clientes para negocios de servicios.

Público objetivo:
- Estéticas y salones de belleza.
- Barberías.
- Peluquerías.
- Estudios de uñas.
- Centros de depilación.
- Negocios de cuidado personal.

La marca debe transmitir:
- Confianza.
- Profesionalismo.
- Innovación.
- Cercanía con los clientes.
- Organización.
- Crecimiento empresarial.

No utilices ilustraciones infantiles, personajes caricaturescos, cerebros de colores ni elementos visuales excesivamente juguetones.

2. PALETA DE COLORES

Utiliza esta paleta de manera consistente en todo el sitio:
- Azul marino profundo: #0B1420
- Azul petróleo oscuro: #142333
- Azul grisáceo: #263747
- Verde olivo principal: #788C3D
- Verde olivo claro: #A7BC68
- Verde salvia: #DCE5C8
- Blanco: #F7F8F5
- Gris claro: #E9ECE7
- Gris de texto: #AAB4BF
- Dorado suave para detalles: #C5A86A

Distribución:
- El azul marino debe dominar la portada y las secciones principales.
- El verde olivo debe destacar botones, palabras clave, iconos, indicadores y elementos interactivos.
- El verde salvia debe utilizarse en fondos secundarios y secciones claras.
- El blanco debe garantizar contraste y legibilidad.
- Evita saturar la página con demasiados colores. El resultado debe verse elegante, sobrio y contemporáneo.

3. DIRECCIÓN DE DISEÑO

Toma como referencia visual la estructura de una landing page SaaS profesional.

Características obligatorias:
- Barra de navegación horizontal y sticky.
- Portada con fondo azul marino.
- Distribución asimétrica de dos columnas.
- Titulares grandes, modernos y contundentes.
- Tipografía sans serif elegante y legible (Manrope, Inter o Plus Jakarta Sans).
- Elementos gráficos con profundidad y sombras suaves.
- Tarjetas con bordes discretos y esquinas redondeadas.
- Botones verdes olivo con contraste adecuado.
- Microanimaciones sutiles al pasar el cursor.
- Transiciones suaves entre secciones.
- Espacios amplios y buena jerarquía visual.
- Alternancia entre secciones oscuras y claras.
- Experiencia excelente en escritorio, tablet y celular.

4. ESTRUCTURA COMPLETA DEL SITIO

A. NAVBAR
- Logotipo CitaIA a la izquierda con isotipo minimalista que combine calendario con seguimiento/confirmación.
- Menú con desplazamiento suave: Inicio, El problema, Nuestra solución, Cómo funciona, Beneficios, Demo, Preguntas frecuentes.
- Botón destacado en verde olivo: "Probar demostración →"

B. HERO / PORTADA
- Fondo azul marino profundo.
- Etiqueta superior: "SEGUIMIENTO INTELIGENTE DE CLIENTES"
- Título principal: "Tus clientes regresan. Tu negocio crece." con "crece" en verde olivo.
- Texto descriptivo: "CitaIA te ayuda a identificar cuándo tus clientes podrían necesitar nuevamente un servicio, organizar su historial y facilitar el seguimiento para que tu negocio no pierda oportunidades de regreso."
- Botones: "Probar demostración →" y "Conocer más"
- Tres beneficios con iconos minimalistas: Seguimiento organizado, Recordatorios oportunos, Clientes más fieles.
- Columna derecha: Mockup profesional de dashboard SaaS de CitaIA con tarjetas, gráficas e indicadores (clientes registrados, próximos seguimientos, % clientes recurrentes, gráfica, actividad reciente, recordatorios pendientes) integrado con fotografía realista de salón/cuidado personal moderno.

C. EL PROBLEMA
- Fondo azul oscuro.
- Título: "¿Cuántos clientes dejas de atender por falta de seguimiento?"
- Cuatro tarjetas con iconos lineales verde olivo: Clientes olvidados, Tiempo perdido, Oportunidades perdidas, Información dispersa.

D. NUESTRA SOLUCIÓN
- Fondo claro (blanco o verde salvia muy tenue).
- Etiqueta: "NUESTRA SOLUCIÓN"
- Título: "Un seguimiento más inteligente para tu negocio."
- Tres elementos visuales: Historial organizado de clientes, Identificación de próximas fechas de seguimiento, Mensajes sugeridos para facilitar el contacto.
- Ilustración/gráfico minimalista y botón "Descubrir cómo funciona →".

E. CÓMO FUNCIONA
- Fondo azul marino.
- Título: "De una visita a una nueva oportunidad."
- Flujo visual horizontal de 4 pasos conectados: REGISTRA, ORGANIZA, IDENTIFICA, CONTACTA con números grandes en verde olivo e iconos minimalistas.

F. DEMOSTRACIÓN INTERACTIVA
- Dashboard funcional con apariencia SaaS.
- Etiqueta: "DEMO INTERACTIVA"
- Título: "Conoce cómo CitaIA transforma los datos en oportunidades."
- Formulario interactivo: Nombre del cliente, Tipo de negocio (Estética, Barbería, Peluquería, Estudio de uñas, Depilación, Otro), Servicio realizado (Corte, Tinte, Manicure, Pedicure, Diseño de uñas, Depilación, Limpieza facial, Tratamiento capilar), Fecha de última visita, Intervalo recomendado (en días).
- Botón "Calcular próximo seguimiento" que calcule dinámicamente:
  - Nombre del cliente, último servicio, fecha estimada de regreso, días restantes, badge de estado (Próximo seguimiento, seguimiento pendiente o fecha futura), recomendación de contacto.
  - Mensaje sugerido generado con plantilla personalizada y botón funcional "Copiar mensaje" (usando portapapeles).
  - Botón para limpiar formulario y presets/datos de ejemplo para demostración rápida en exposición.
  - Nota discreta de que es un prototipo académico sin IA externa ni almacenamiento permanente.

G. BENEFICIOS
- Fondo claro.
- Título: "Más que recordar citas: construir relaciones con tus clientes."
- 5 beneficios: Organización, Seguimiento, Personalización, Fidelización, Crecimiento.

H. PREGUNTAS FRECUENTES
- Fondo azul oscuro con acordeones funcionales respondiendo con transparencia sobre el prototipo académico.

I. CIERRE / CONTACTO
- Fondo azul marino con acentos verde olivo: "Cada cliente que regresa es una nueva oportunidad." y botón "Explorar demostración →".

J. FOOTER
- Logotipo, eslogan, enlaces a secciones, "Prototipo académico — CitaIA", año 2026.

5. REQUISITOS TÉCNICOS Y GITHUB PAGES
- Todo ejecutado localmente en el navegador (React, TypeScript, Tailwind CSS, Lucide icons, Vite).
- Sin backend ni APIs externas requeridas. Navegación por anclas internas suaves.
- Configuración de Vite compatible con base configurable para GitHub Pages y workflow de GitHub Actions listo para deploy.
